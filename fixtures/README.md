# Fixtures

- `storefront/`: a small checkout service, the repository every test and eval
  works on. Its `POST /checkout` path is the one in the System Editor mockup:
  gateway (3 s timeout) → controller → `placeOrder` → reserve stock → capture
  with Stripe → save with an outbox row → `order.placed` → email worker
  (an inferred edge). The README carries one deliberate typo ("recieve") for
  the low-risk eval.
- `storefront.model.json`: the hand-checked map of `storefront/`. Generated by
  `node scripts/gen-fixture-model.mjs`, which finds every line number by
  searching for marker text, so it can't silently drift from the code. Tests
  validate it against the files on every run.
